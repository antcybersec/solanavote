# **App Name**: SolanaVote

## Core Features:

- Wallet Connect: Connect to Solana wallet using Phantom or other Solana wallet adapters.
- Cast Vote: Display the active poll with voting options. Each wallet can vote only once. Store the vote on-chain.
- Display Results: Show real-time vote counts for each option, updating dynamically as votes are cast.

## Style Guidelines:

- Primary color: Solana's signature purple (#9945FF) as a base.
- Secondary color: A vibrant teal (#2DD4FF) to complement the purple and add a modern feel.
- Accent: Bright pink (#FF49DB) for interactive elements and highlights, reinforcing the gamified look.
- Use a layered design with floating elements to create depth and visual interest.
- Incorporate custom Solana-themed icons with a 3D, glossy appearance.
- Subtle, engaging animations for button hovers, vote confirmations, and result updates.
